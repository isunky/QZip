# RC2 验收记录

`v1.0.0-rc.2` 重点收口影响核心功能和日常体验的问题，不代表 Windows V1.0 总验收完成。

## 本轮完成

- Windows 原生拖放路径分类：单压缩包、多压缩包、普通文件/文件夹和混合内容。
- 多压缩包批量解压确认流程及同名目录默认输出。
- 后端能力驱动的创建格式和密码入口禁用。
- 压缩包目录服务端搜索、每页 500 项分页及追加加载。
- 正确区分密码错误、损坏包和不支持格式，避免错误密码提示。
- 任务详情、错误代码、告警、打开结果和打开位置入口。
- Windows release 构建性能与异常恢复基线。

## 必须验证

1. 拖入单个 ZIP/7Z 时进入快速解压；拖入多个压缩包时进入批量解压；拖入普通或混合内容时进入创建页。
2. 批量解压为每个安全、无密码压缩包创建独立任务，加密或风险包只提示单独处理。
3. 搜索结果来自完整压缩包目录而非仅当前 500 项；“加载更多”不会产生重复行。
4. 损坏包显示可操作错误，不弹出密码框；错误密码仍可原地输入并重试。
5. 已完成和失败任务能够查看技术详情与目标位置；已完成任务能够打开结果。
6. `pnpm check`、Rust fmt/clippy/test、Sidecar 核心回归和 Windows release/NSIS 构建通过。
