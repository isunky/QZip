# 轻压 QZip 文件图标主题与自定义功能构想

> 文档状态：产品构想  
> 目标平台：Windows 10/11  
> 建议名称：文件图标主题 / Icon Packs

## 背景

对于压缩软件来说，文件类型图标不只是装饰，而是产品体验和品牌识别的一部分。

主应用图标通常只出现在开始菜单、任务栏和应用窗口中；ZIP、7Z、RAR、ISO 等文件图标则会长期出现在资源管理器、桌面和下载目录。设计良好的文件类型图标可以带来三方面价值：

- **提高识别效率**：用户可以通过颜色和图形快速判断压缩格式。
- **改善视觉体验**：避免所有压缩文件都显示成完全相同的图标。
- **增强品牌曝光**：即使没有打开轻压，用户仍然能够感知产品设计。

文件图标已经是轻压区别于传统压缩软件的重要视觉资产。后续开放图标主题和自定义能力，可以进一步形成具有辨识度的产品特色。

## 产品定位

该功能建议使用“文件图标主题”或“Icon Packs”作为面向用户的名称，而不是直接使用“自定义 ICO”。

“图标主题”更容易被普通用户理解，也适合后续形成社区图标包、主题分享和创作者生态。

推荐宣传语：

> 不只是打开压缩文件，也让你的资源管理器更好看。

## 设计原则

1. 默认图标必须保持完整、美观，不要求用户进行任何配置。
2. 个性化能力放在设置页中，不增加首次使用和核心压缩流程的复杂度。
3. 更换前提供清晰预览，修改后允许一键恢复默认。
4. 用户配置在升级后继续保留。
5. 自定义资源必须经过安全校验，不能成为加载任意可执行文件的入口。
6. 图标切换不能破坏现有文件关联和“打开方式/QZip”。

## 功能分层

### 1. 内置图标主题

提供由轻压官方维护的完整文件图标套装，例如：

- 默认剪纸风格。
- 现代极简风格。
- 深色资源管理器适配风格。
- 高对比度或无障碍风格。

用户选择主题后，ZIP、7Z、RAR、TAR、ISO 等格式的图标整套切换。

### 2. 单独修改文件类型图标

允许用户针对某一种格式单独替换图标，而不影响其他格式，例如：

- 将 ZIP 替换为自定义蓝色图标。
- 保留默认 7Z 和 RAR 图标。
- 为未知或其他归档格式单独设置通用回退图标。

每个格式应提供以下操作：

- 选择自定义图片。
- 预览资源管理器显示效果。
- 恢复该格式默认图标。

### 3. 导入和导出图标包

允许用户将完整图标主题打包、安装和分享。

建议图标包包含：

- 图标包名称、作者和版本。
- 支持的轻压最低版本。
- 每种文件格式对应的图标文件。
- 通用归档回退图标。
- 可选的浅色、深色和高对比度预览信息。
- 图标资源的 SHA-256 校验值。

图标包只能包含图片和描述文件，不能包含脚本、DLL 或可执行文件。

## 设置页结构建议

```text
设置
└── 文件类型
    ├── 文件关联
    ├── 图标主题
    │   ├── 默认剪纸
    │   ├── 现代极简
    │   ├── 高对比度
    │   └── 自定义
    ├── 单独设置文件图标
    │   ├── ZIP
    │   ├── 7Z
    │   ├── RAR
    │   ├── TAR
    │   ├── ISO
    │   └── 更多格式
    ├── 导入图标包
    ├── 导出当前图标包
    └── 恢复默认图标
```

设置页应使用图标网格进行主题预览，并显示资源管理器中的小图标、中图标和大图标效果。

## Windows 实现约束

### 稳定资源路径

用户导入的图标不能直接引用下载目录、桌面或移动磁盘中的原文件。轻压应在验证后，将资源复制到稳定的应用数据目录，例如：

```text
%LocalAppData%\QZip\IconPacks\<pack-id>\
```

文件关联注册表只能引用该稳定目录中的 ICO 文件。

### 图标尺寸

导入 PNG 后，应自动生成包含以下常用尺寸的 ICO：

- 16×16
- 24×24
- 32×32
- 48×48
- 64×64
- 128×128
- 256×256

生成时需要保证透明背景、视觉边距和小尺寸清晰度。不能只将一张大图直接缩放到所有尺寸，重要图标可以提供小尺寸专项优化。

### 文件关联

每种格式继续使用独立 ProgID，例如：

```text
QZip.zip
QZip.7z
QZip.rar
QZip.iso
```

每个 ProgID 的 `DefaultIcon` 指向对应图标文件，避免修改一个格式时导致所有压缩文件一起变化。

### 图标缓存刷新

更新注册表后，需要安全通知 Windows Shell 刷新文件关联和图标显示。

优先使用系统通知机制刷新资源管理器。只有在必要时才提供重建图标缓存选项，不能未经确认强制终止 Explorer 进程。

### 安装、升级和卸载

- 应用升级必须保留用户安装的图标包和当前选择。
- 更新内置图标时不能覆盖用户的自定义配置。
- 卸载时需要恢复或移除 QZip 对应的文件关联。
- 用户图标包是否保留，应由卸载选项或明确的数据保留策略决定。
- 重新安装后，可以选择检测并恢复已有图标配置。

## 安全要求

- 默认只接受 `.ico` 和 `.png` 文件。
- 不允许从 EXE、DLL、CPL、SCR 等二进制文件中提取或引用图标。
- 限制单个文件和整个图标包的大小。
- 校验图片格式、实际内容、尺寸和解码结果，不能只检查扩展名。
- 图标包解压时阻止路径穿越、绝对路径和符号链接。
- 图标包描述文件采用固定结构，不支持执行脚本和动态代码。
- 导入失败时不修改现有文件关联。

## 建议的数据模型

```json
{
  "schemaVersion": 1,
  "id": "qzip-default-paper-cut",
  "name": "默认剪纸",
  "author": "QZip",
  "version": "1.0.0",
  "minimumQZipVersion": "1.2.0",
  "icons": {
    "zip": "zip.ico",
    "7z": "7z.ico",
    "rar": "rar.ico",
    "tar": "tar.ico",
    "iso": "iso.ico",
    "archive": "archive.ico"
  }
}
```

实际支持的格式集合应与轻压的文件关联能力保持一致。

## 建议实施阶段

### 第一阶段：内置主题切换

- 增加图标主题设置页。
- 提供默认主题和一套实验主题。
- 支持整套切换和恢复默认。
- 验证文件关联、升级和卸载行为。

### 第二阶段：单格式自定义

- 支持导入 ICO 或 PNG。
- 自动生成多尺寸 ICO。
- 支持单个格式恢复默认。
- 增加图标缓存刷新和错误恢复。

### 第三阶段：图标包生态

- 定义图标包格式和版本兼容规则。
- 支持导入、导出和分享。
- 提供官方图标包示例与创作指南。
- 根据社区规模评估是否建设在线主题库。

## 验收重点

- ZIP、7Z、RAR 等格式可以显示不同图标。
- 整套主题和单格式图标均能正确切换。
- 重启应用和资源管理器后配置仍然有效。
- 应用升级后自定义图标不会丢失。
- 恢复默认后，注册表和图标文件状态一致。
- 删除原始导入图片不会影响已经应用的图标。
- 无效或恶意图标包不会修改系统配置。
- 高 DPI、小图标和大图标模式下均保持清晰。
- 功能失败时不会破坏“打开方式/QZip”和现有文件关联。

## 产品价值判断

文件图标主题不应取代稳定性、可信签名和核心压缩能力的优先级，但它适合作为轻压具有辨识度的个性化功能。

如果完成度足够高，这项功能可以同时增强：

- 产品视觉差异。
- 用户对文件格式的识别效率。
- 社区参与和主题创作空间。
- 资源管理器中的长期品牌曝光。

最终目标不是简单提供“更换 ICO”，而是让轻压形成一套安全、稳定、易分享的 Windows 文件图标主题体系。
